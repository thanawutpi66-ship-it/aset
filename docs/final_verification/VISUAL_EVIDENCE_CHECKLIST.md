# Visual Evidence Checklist

Capture genuine images/video with original files and timestamps. Do not annotate away safety details or synthesize missing views.

## Physical photos

- [ ] Battery specimens and readable labels/serials
- [ ] PSW and PEL front panels/model/serials
- [ ] Overall bench layout
- [ ] Kelvin Force/Sense wiring at the battery
- [ ] MLX90614 location, angle and distance to target
- [ ] SSR identity, wiring and state indication
- [ ] Circuit breaker and independent disconnect
- [ ] E-STOP button and surrounding controls
- [ ] C10 active setup
- [ ] Pulse-DCIR active setup

## GUI / data capture

- [ ] Battery Profile and selected product/serial
- [ ] Validation campaign identity and frozen configuration
- [ ] Automated sequence/profile and protocol revision
- [ ] Live V/I/T with source/freshness visible
- [ ] Raw CSV schema and first/last rows
- [ ] Metadata JSON including software SHA and terminal status
- [ ] Grading result and its eligibility/basis fields
- [ ] Fault alarm and safe-state indication
- [ ] OTP configured value
- [ ] OTP runtime-effective value/consumer evidence
- [ ] Session identity, campaign ID, specimen ID and run index

## Video/frame sequence

- [ ] E-STOP state before trigger
- [ ] Trigger action by the operator
- [ ] Alarm and sequence response
- [ ] Resulting safe state, with instrument indicators visible
- [ ] SSR ON/OFF observable state and independent load/current state

**[MANUAL PHYSICAL ACTION — USER/TEAM ONLY]** Physical photos and videos are collected only by the operator/team during an approved safe procedure. A telemetry observation is not a relay switching-time measurement.
