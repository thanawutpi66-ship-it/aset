## Reuse, new testing, and decisions

- **Potentially reusable for development analysis only:** repository `sessions/*.csv` and sidecars listed in `EXISTING_EVIDENCE_INVENTORY.md`; unit/simulation test coverage; profile constants and prior historical logs.
- **Raw-data reanalysis:** sampling/logging cadence, row completeness, temperature freshness, and pulse-pair timing may be recalculated from eligible raw rows only after field semantics and QC are frozen.
- **Must fix or gate before Final acquisition:** strict traceability bundle acceptance; grade result-to-session linkage; closed Final profile denominator.
- **Method decisions:** Req.1 Final profile set and replicate denominator; Req.3 single primary cadence statistic (while preserving all diagnostics); Req.6 pulse-to-run aggregate, pulse QC and number/independence of repeats; Req.8 reference and convergence/sustain rule; Req.10 defined safe fault set and denominator.
- **Requires new physical evidence:** Req.2–5, 7–12 where actual acquisition, cell/pack behavior, sensor freshness, hardware response or Final specimen measurements are part of the criterion. Software tests do not replace them.

No historical development record is promoted to Final evidence.
